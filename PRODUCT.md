# Product

## Register

product

## Users

Richard uses this personal prompt library from a home computer, work browser, and phone. The app is a self-hosted fork of prompts.chat backed by Neon, with Vercel as the intended deployment target.

## Product Purpose

Find the right thinking method, fill in its context, and reuse it in an AI tool. Preserve existing search, filtering, prompt creation, detail, and collection routes. Styling must not imply that an empty database already contains prompts or that login is configured.

## Brand Personality

Personal, imaginative, quietly theatrical. Richard explicitly likes anime UI and Rikka Takanashi from Love, Chunibyo & Other Delusions. He selected the name “Richard · 邪王真眼档案馆”. The current implementation direction is a character-themed workspace, with standard tool controls and restrained character language.

## Anti-references

Do not inherit the original site's unrelated conference announcements, sponsors, app promotions, or stock community positioning. Avoid a generic SaaS dashboard, unreadable artwork behind text, autoplay audio, and a character showcase that buries the prompt workflow.

## Design Principles

1. Give Richard a recognizable personal place while keeping the prompt workflow familiar.
2. Use the character as a focal point, not as background noise behind every control.
3. Preserve real data and empty states; do not fabricate saved prompts or activity.
4. Keep route URLs, filtering, authentication behavior, and database schema intact.
5. Support desktop and mobile with the same content and obvious controls.

## Accessibility & Inclusion

Use WCAG AA contrast as the engineering baseline, visible keyboard focus, semantic labels, touch-friendly targets, and reduced-motion alternatives. No autoplay audio, flashing, or motion required to use the interface.
